One original fortune-cookie line for a software developer, written for the
[make.fun](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44) competition "Fortune Cookie Wisdom for Developers". `main.ts` writes it to `/output/entry.txt`:

> The comment you write today is the only teammate who will never leave the team.

Run it with `node main.ts` (Node 22.18+).
